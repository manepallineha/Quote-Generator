# 🌈 Mood Quote Generator

A simple and interactive web app that displays quotes based on your mood.

## ✨ Features
- 🎭 Mood-based quotes (Happy, Sad, Demotivated)
- 🎨 Dynamic UI with color themes
- ✨ Smooth animations & typing effect
- 📋 Copy quote feature
- 📱 Share to WhatsApp
- ❤️ Save favorite quotes (local storage)

## 🚀 Tech Used
- HTML
- CSS
- JavaScript

## 🎯 How it works
Select your mood and get a random quote that matches your feelings.

## 💡 Future Improvements
- API-based quotes
- More moods
- Mobile app version
